%APP_BOLD% - AI coding assistant with read, bash, edit, write tools

~Usage:
  %APP% [options] [@files...] [messages...]

~Commands:
  %APP% install <source> [-l]     %COMMAND_install%
  %APP% remove <source> [-l]      %COMMAND_remove%
  %APP% uninstall <source> [-l]   %COMMAND_uninstall%
  %APP% update [source|self|%APP%]   %COMMAND_update%
  %APP% list                      %COMMAND_list%
  %APP% config                    %COMMAND_config%
  %APP% <command> --help          Show help for install/remove/uninstall/update/list

~Options:
  --provider <name>              %OPTION_provider%
  --model <pattern>              %OPTION_model%
  --api-key <key>                %OPTION_api-key%
  --system-prompt <text>         %OPTION_system-prompt%
  --append-system-prompt <text>  %OPTION_append-system-prompt%
  --mode <mode>                  %OPTION_mode%
  --print, -p                    %OPTION_print%
  --continue, -c                 %OPTION_continue%
  --resume, -r                   %OPTION_resume%
  --session <path|id>            %OPTION_session%
  --fork <path|id>               %OPTION_fork%
  --session-dir <dir>            %OPTION_session-dir%
  --no-session                   %OPTION_no-session%
  --models <patterns>            %OPTION_models%
  --no-tools, -nt                %OPTION_no-tools%
  --no-builtin-tools, -nbt       %OPTION_no-builtin-tools%
  --tools, -t <tools>            %OPTION_tools%
  --thinking <level>             %OPTION_thinking%
  --extension, -e <path>         %OPTION_extension%
  --no-extensions, -ne           %OPTION_no-extensions%
  --skill <path>                 %OPTION_skill%
  --no-skills, -ns               %OPTION_no-skills%
  --prompt-template <path>       %OPTION_prompt-template%
  --no-prompt-templates, -np     %OPTION_no-prompt-templates%
  --theme <path>                 %OPTION_theme%
  --no-themes                    %OPTION_no-themes%
  --no-context-files, -nc        %OPTION_no-context-files%
  --export <file>                %OPTION_export%
  --list-models [search]         %OPTION_list-models%
  --verbose                      %OPTION_verbose%
  --offline                      %OPTION_offline%
  --help, -h                     %OPTION_help%
  --version, -v                  %OPTION_version%

Extensions can register additional flags (e.g., --plan from plan-mode extension).%EXTENSION%

~Examples:
  # Interactive mode
  %APP%

  # Interactive mode with initial prompt
  %APP% "List all .ts files in src/"

  # Include files in initial message
  %APP% @prompt.md @image.png "What color is the sky?"

  # Non-interactive mode (process and exit)
  %APP% -p "List all .ts files in src/"

  # Multiple messages (interactive)
  %APP% "Read package.json" "What dependencies do we have?"

  # Continue previous session
  %APP% --continue "What did we discuss?"

  # Use different model
  %APP% --provider openai --model gpt-4o-mini "Help me refactor this code"

  # Use model with provider prefix (no --provider needed)
  %APP% --model openai/gpt-4o "Help me refactor this code"

  # Use model with thinking level shorthand
  %APP% --model sonnet:high "Solve this complex problem"

  # Limit model cycling to specific models
  %APP% --models claude-sonnet,claude-haiku,gpt-4o

  # Limit to a specific provider with glob pattern
  %APP% --models "github-copilot/*"

  # Cycle models with fixed thinking levels
  %APP% --models sonnet:high,haiku:low

  # Start with a specific thinking level
  %APP% --thinking high "Solve this complex problem"

  # Read-only mode (no file modifications possible)
  %APP% --tools read,grep,find,ls -p "Review the code in src/"

  # Export a session file to HTML
  %APP% --export ~/%CONFIG%/agent/sessions/--path--/session.jsonl
  %APP% --export session.jsonl output.html

~Built-in Tool Names:
  read   - Read file contents
  bash   - Execute bash commands
  edit   - Edit files with find/replace
  write  - Write files (creates/overwrites)
  grep   - Search file contents (read-only, off by default)
  find   - Find files by glob pattern (read-only, off by default)
  ls     - List directory contents (read-only, off by default)
