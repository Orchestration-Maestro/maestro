# Select an ideation lens

## SCAMPER

Use for transforming an existing product or process. Substitute a part or audience; combine separate ideas;
adapt a technique from another domain; modify scale; put it to another use; eliminate steps; reverse the order
or who performs the work. Pick operations that challenge the current shape rather than running a ritual list.

## How Might We

Use when someone is anchored on a solution. Start from observed pain and ask how to obtain an outcome for a
specific user within a constraint. Try several framings. A request to add a particular button is too narrow;
"make everyone happy" is too broad. The question should permit different testable solutions.

## First principles

Use when every option is only an incremental variation. Separate known truths from assumptions, challenge
convention and rebuild an approach from what is actually true. Do not relabel an unsupported belief as a fact.

## Jobs to Be Done

Use when the real problem is unclear. Ask about the functional task, the emotional outcome and how the user
wants to be perceived. Frame it as "When I am in this situation, I want this, so I can achieve that outcome."
Compare against the current workaround, which may not be a competing product in the same category.

## Constraint-based ideation

Use when an idea grows too large or vague. Explore an explicitly hypothetical limit on time, features,
technology, cost, audience or scale. Ask what survives if there is only one feature or much less time.
These are thinking aids, not newly agreed project limits.

## Pre-mortem

Use to evaluate a promising direction. Imagine it has shipped and failed. List technical, market, team and
timing causes; ask which are preventable, which require changing direction and which risks are acceptable.
A possible failure is a hypothesis to test, not a report of an event that happened.

## Analogous inspiration

Use to widen the option set. Find structural similarities in other industries, natural systems or historical
approaches. Borrow the solution to a shared coordination or trust problem rather than copying surface branding
or merely saying that a product should look like another product.
