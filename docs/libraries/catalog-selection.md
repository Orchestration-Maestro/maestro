## Approved model-selection libraries

`maestro-catalog` enables the `collation` feature of `maestro-text` on every
target; see [text libraries](text.md) for the ICU packages. The comparator accepts
a caller-supplied environment reader and exposes no ICU type. Existing `indexmap =2.14.2` with defaults and `serde`
(MIT OR Apache-2.0) holds ordered mutable provider defaults. `owo-colors =4.2.1`
(MIT, no features) styles warning lines. Internal dependencies are models,
credentials, the text leaf and the file-pattern leaf, whose case-insensitive matcher resolves
scope globs. See [model selection](../selection.md).
