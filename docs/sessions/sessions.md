# Sessions

Entry points for the session crate:

- [Session history](session_manager.md): records, appends, names, summaries, the
  read-only view and native JSONL files.
- [Labeled history trees](../tree.md): tree reads, labels and resetting the selection.
- [Message projection](messages.md): application messages converted for model requests.
- [Session format](session_format.md): the JSONL records, versions, context construction and operation index.
- [Session discovery](../discovery.md): project and all-project listing, progress, and missing working-directory diagnosis.
- [Settings guide](settings.md): the user-facing settings guide; [the settings reference](../settings.md) owns defaults.
